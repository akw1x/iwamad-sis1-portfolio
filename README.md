# Personal Portfolio Website

Live Demo: [https://akw1x.github.io/iwamad-sis1-portfolio/](https://akw1x.github.io/iwamad-sis1-portfolio/)

## Overview
This is an individual single-page portfolio website built for the SIS 1 assignment in Foundational Web Interface Development. The page highlights my background in IT Management at KBTU and UI/UX design, showcases recent project builds, and provides an interactive contact form with custom JavaScript validation.

## Showcased Projects
1. **Interactive Mobile & Web App Dev:** Modern web UI/UX builds and cross-platform component design.
2. **iOS Application Development:** Native mobile UI experiments and Swift component layouts.
3. **ReLoop (C2C Marketplace):** Project Management coursework case study highlighting interactive UI/UX prototyping and live demo layout without back-end functionality.

## Key Design Decisions
1. **Layout Strategy:** Implemented a mobile-first responsive layout where the selected works grid transforms from a single-column view on mobile screens (375px) to a 3-column grid on desktop viewports (1200px) using CSS Grid.
2. **Color & Theme System:** Built a light/dark color system using CSS Custom Properties switched instantly by toggling a `data-theme` attribute on the root HTML element.
3. **Mobile Optimization & Accessibility:** Adjusted touch targets and container margins to eliminate horizontal scrolling on 375px screens, ensured a minimum font size of 14px, and added visible keyboard focus indicators.
